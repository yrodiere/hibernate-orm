[[final-field-check]]
== Boot-time check for final persistent fields

Hibernate now checks on boot for persistent fields declared `final` that will need to be set through reflection.
Such reflective mutation of final fields is deprecated starting with JDK 26 and will be denied in a future JDK version.

The bytecode enhancer automatically removes the `final` modifier from persistent fields, resolving these warnings.
Alternatively, remove the `final` modifier from the field declarations.

The behavior of this check is controlled by the `hibernate.mapping.final_persistent_fields` setting,
which accepts values `warn` (the default), `error`, and `ignore`.

See the link:{userGuideBase}#entity-pojo-final-fields[User Guide] for details.

[[schema-if-exists]]
== Schema DDL uses `IF EXISTS` / `IF NOT EXISTS`

Schema management DDL now uses `CREATE SCHEMA IF NOT EXISTS` and `DROP SCHEMA IF EXISTS` for dialects which support these clauses, avoiding warnings when a schema already exists or has already been dropped.

Supported dialects: PostgreSQL, CockroachDB, H2, HSQLDB, SAP HANA, and SQL Server (DROP only, version 13+).
